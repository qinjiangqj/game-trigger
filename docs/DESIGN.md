## 1. 游戏规则

引擎支持两种模式：**经典轮盘**（`classic`）与**恶魔轮盘**（`buckshot`）。

### 1.1 经典轮盘（classic）

| 要素 | 说明 |
|------|------|
| 武器 | 六槽左轮手枪，装填 1 发实弹与 5 发空枪，实弹槽位随机分布 |
| 回合 | 当前行动者选择目标后扣动扳机，按弹巢指针顺序击发 |
| 重装 | 弹巢六发全部击发后自动重新随机装填 |

**行动结果**

| 行动 | 命中实弹 | 命中空枪 |
|------|----------|----------|
| 自击 | 出局，对方获胜 | **连庄**——保留回合权，继续行动 |
| 击敌 | 击杀对方，立即获胜 | 无事发生，**交换回合权** |

### 1.2 恶魔轮盘（buckshot）

致敬 *Buckshot Roulette* 的电荷生命制变体：

| 要素 | 说明 |
|------|------|
| 武器 | 霰弹枪，每次装填 2–8 发，实/空弹数量随机（最少各 1 发） |
| 配比公开 | 装填时向双方公开剩余实弹/空弹**数量**，但**顺序**未知 |
| 生命 | 每人以**电荷**（默认 3，可配 2–4）计命，中弹扣 1，归零出局 |
| 重装 | 弹仓打空后自动重新随机装填，并公开新配比 |

**行动结果**

| 行动 | 命中实弹 | 命中空枪 |
|------|----------|----------|
| 自击 | 自身电荷 −1；归零则出局，存活则**移交回合** | **蝉联**——保留回合权 |
| 击敌 | 对方电荷 −1；归零则己方获胜，否则**移交回合** | 无事发生，**移交回合** |

与经典模式的关键差异：自击实弹不再即死（扣 1 电荷并移交回合），攻击是唯一直接造成伤害的手段；配比公开使每回合都是一次显式期望值计算。

### 1.3 决斗轮盘（duel）

模型竞技场使用的对局形态：**双方各持一把**独立随机装填的左轮。

| 要素 | 说明 |
|------|------|
| 武器 | 每人一把左轮（默认六槽、各装 1 发实弹，槽位/实弹数可配），装填互相独立 |
| 击发 | 当前行动者**用自己的枪**选择自击或击敌，按各自弹巢指针顺序击发 |
| 重装 | 各自弹巢打空后自动重新随机装填，互不影响 |

**行动结果**（与经典模式同构）

| 行动 | 命中实弹 | 命中空枪 |
|------|----------|----------|
| 自击 | 出局，对方获胜 | **连庄**——保留回合权，继续行动 |
| 击敌 | 击杀对方，立即获胜 | 无事发生，**交换回合权** |

与经典模式的关键差异：两把枪的装填序列完全独立，行动者面对的 `p0`（实弹概率）永远是**自己**这把枪的剩余配比。自击空弹连庄会持续烧掉自己枪里的空弹——自己的枪越打越"烫"，何时转向击敌成为独立的节奏博弈。双方弹巢的剩余数量公开、顺序保密。

### 1.4 道具系统（buckshot 专属）

开局及每次重装时，双方各补发 2 个随机道具（道具栏上限 8）。道具在**射击前**的道具阶段使用，**不消耗回合**。`item_set` 参数可选：`none`（关闭）、`standard`（标准 5 件套）、`full`（全量 9 件，追加 *Double or Nothing* 4 件）；经典/决斗模式强制无道具。

**标准 5 件套**

| 道具 | 图标 | 类别 | 效果 |
|------|------|------|------|
| 放大镜 | 🔍 | 信息 | 查看当前弹是实是空（**仅自己可见**，写入私有信息集） |
| 啤酒 | 🍺 | 节奏 | 退掉当前弹，退出的弹型**公开**；退光弹仓立即重装 |
| 香烟 | 🚬 | 恢复 | 回复 1 电荷（不超上限；满血禁用） |
| 手锯 | 🪚 | 伤害 | 下次实弹伤害 **×2**（状态公开，任意一次射击后清除） |
| 手铐 | 🔗 | 节奏 | 跳过对方下一回合（不可连续铐同一人，重装后重置） |

**DoN 追加 4 件**

| 道具 | 图标 | 类别 | 效果 |
|------|------|------|------|
| 反转器 | 🔄 | 复合 | 当前弹实↔空互换（结果仅自己可见；偷看过该弹者的私有信息同步翻转） |
| 电话 | 📱 | 信息 | 随机获知一发未来弹的位置与类型（仅自己可见，指针前移后自动重映射） |
| 过期药 | 💊 | 赌博 | 五五开：+2 电荷 或 −1 电荷（**电荷归零直接出局**） |
| 肾上腺素 | 💉 | 复合 | 偷取对方一个道具并立即使用（不可偷肾上腺素；仅偷当前可用道具） |

**肾上腺素偷取优先级**：收尾手铐（对方濒死）＞已知实弹手锯 ＞ 濒死过期药 ＞其余按可用性择优；偷来的道具立即递归结算效果。

**私有信息集与信息公平**：放大镜/电话获知的弹型仅写入使用者 `known_shells`，反转器使用后双方已偷看该弹的信息同步翻转；弹仓指针前移（射击/啤酒退弹）后知识自动重映射。双方**道具栏内容与数量公开**，手锯/手铐生效状态公开。服务端 `get_state(viewer)` 按观察者过滤私有事件载荷与对手 `known_shells`，WebSocket 按连接携带的 `viewer` 推送差异化状态——人类玩家永远看不到 AI 的私有情报（偷看事件显示为"已打码"）。

### 1.5 锦标赛赛制

- **赛制**：六人循环赛（Round-Robin），每位选手与其余五人各战一场，共 15 局
- **排名**：按胜场数降序排列，胜场相同则并列同名次
- **先手**：每对选手的先手方随机分配
- **模式**：经典/决斗/恶魔轮盘均可作为锦标赛赛制，各模式的选手参数一致

## 2. AI 决策模型

### 2.1 选手属性

每位 AI 选手由四个静态性格参数与一个动态状态变量共同刻画：

| 符号 | 名称 | 含义 | 取值范围 |
|------|------|------|----------|
| $R$ | 攻击阈值 | p0 超过此值倾向攻击，越低越早攻击保命 | $[0, 1]$ |
| $S$ | 策略惯性 | 值越高越倾向沿用上回合决策 | $[0, 1]$ |
| $C$ | 冷静系数 | 值越高越不受情绪波动干扰 | $[0, 1]$ |
| $L$ | 随机波动 | 决策噪声的幅度上限 | $[0, 1]$ |
| $M$ | 实时心态 | 正值为亢奋（偏攻击），负值为畏缩（偏保守） | $[-1, 1]$ |

### 2.2 经典模式决策流程

每回合决策分两步执行。

**第一步：惯性判定**

以概率 `S_real` 直接复用上回合选择，跳过重新分析。惯性随 p0 上升衰减——越危险越不能靠习惯。

```
S_real = max(0,  S × (1 − p0) − 0.05 × 连败数)
```

**第二步：攻击倾向计算**

若惯性判定未通过，则基于当前弹巢状态计算攻击倾向。令 `p0 = 剩余实弹数 / 剩余总槽数`。

**（A）Sigmoid 攻击倾向**：`base = 1 / (1 + e^(-K × (p0 − R)))`，`K = 4.0` 为切换锐度。`R` 直接作为攻击阈值。

**（B）蝉联期权修正**：`option = 0.15 × R × (1 − p0)`，`base = max(0.02, sigmoid − option)`。R 越高越看重蝉联（赌徒博连庄），R 越低越早出手保命。

> 注：`base` 有 0.02 下限防止极端 p0 下攻击欲归零；冷静修正 `calm_factor = max(0.0, 1 − C × |M|)` 有安全截断；p0≥1 时攻击欲下限 0.51 确保裁决必为攻击。

**（C–G）人格调制链**：

```
a1 = base + M × 0.25                    心态修正
a2 = a1 × (1 − C × |M|)                 冷静修正
a3 = a2 + δ,  δ ∈ U(−L, L)              随机扰动
attack = clamp(a3, 0, 1)
choice = opponent (attack > 0.5) / self
```

**边界情形**

| 条件 | 行为 |
|------|------|
| `p0 ≤ 0`（弹巢全空） | 直接选择自击——连庄严格优于交换回合 |
| `p0 ≥ 1`（仅剩实弹） | `base = 1.0`，强制攻击——自击等同自杀 |

**心态更新机制**

| 事件 | 公式 | 约束 |
|------|------|------|
| 获胜 | `M += 0.08 + 0.02 × 连胜数` | `M ≤ 1.0` |
| 战败 | `M -= 0.10 + 0.03 × 连败数` | `M ≥ -1.0` |
| 轮空 | `M *= 0.8` | — |

每局开始前，心态衰减至 70%（`M *= 0.7`），模拟赛间冷静期。

### 2.3 恶魔轮盘：效用决策内核

恶魔轮盘模式下配比公开，决策不再用 sigmoid 倾向，而是显式比较两个行动的**期望效用**（EU）。

令 `p` 为下一发实弹概率（公开信息），`T` 为蝉联时机价值，三个杀伤权重 `λ` 由 $R$ 派生：

```
λ_kill = 1.5 − 2R        击敌收益：R 低（谨慎）→ 攻击保命型
λ_own  = 0.8 + 1.2R      自伤代价：R 高（赌徒）→ 不在乎自击
λ_give = 0.5 + 0.8R      交权代价：R 高 → 更怕把回合权拱手让人

T = 0.5 + 0.3·|2p−1| + 0.25·(对方电荷−我方电荷)/max(电荷)   ← 蝉联时机价值
```

**期望效用与裁决**

```
EU(自击) = (1−p)·T + p·(−λ_own)
EU(击敌) = p·λ_kill + (1−p)·(−T·λ_give)

diff = EU(击敌) − EU(自击) + (0.25 − R)·0.6
→ 心态平移：  diff += M × 0.25
→ 冷静压制：  diff ×= (1 − C·|M|)
→ 随机扰动：  diff += U(−L, L) × 0.5
choice = 击敌 (diff > 0) / 自击 (diff ≤ 0)
```

**边界情形**：`p = 0`（确定空弹）→ 强制自击蝉联；`p = 1`（确定实弹）→ 强制击敌。

人格调制链（心态→冷静→噪声）作用于**效用差**而非攻击倾向，与经典模式同构——保证两种模式下选手性格表现一致。

### 2.4 道具阶段决策（启发式）

带道具时每回合先进入**道具阶段**：循环调用启发式 `next_item_action` 直到无道具可用，然后才射击。

**信息融合**——实弹概率 p 不再只用公开配比：

```
p_live = 已知当前弹型 ? (实弹 ? 1 : 0)          ← 放大镜私有信息优先
                       : 剩余实弹数 / 剩余弹数   ← 退化为公开比例
```

**人格化道具倾向**（每个道具每次道具阶段只掷骰一次，防止重试把人格概率磨平）：

| 道具 | 使用倾向 | 人格调制 |
|------|----------|----------|
| 放大镜 | 弹仓不确定（实/空皆有）时侦察 | `0.15 + 0.85×(0.35×(1−S) + 0.65×C)`——冷静求证为主，惯性少动脑为辅 |
| 啤酒 | p ∈ [0.2, 0.8]（不确定性最大）且未看过当前弹 | 固定 0.7；已知当前弹型则永不退（浪费确定性） |
| 香烟 | 掉血就用 | 硬校验拦截满血 |
| 手锯 | 已知当前为实弹时磨锯 | `1 − 0.6×R`——R 低（谨慎）更果断 |
| 手铐 | 对方剩 1 电荷（收尾）或自己有信息优势 | `0.4 + 0.6×C`——冷静者优先节奏压制 |
| 反转器 | 已知当前为实弹（反转自击蝉联）或实弹占比低且对方残血（反转赌实弹收尾） | 蝉联稳招 `0.55 + 0.35×C`；赌收尾 `0.2 + 0.6×R` |
| 电话 | 弹仓剩余弹多且当前弹未知时侦察未来 | 信息型人格偏好（低 R 高 C） |
| 过期药 | 濒死（1 电荷）时五五开赌命；非濒死小概率博上限 | 濒死 `0.75×R`；平时 `0.15 + 0.35×R` |
| 肾上腺素 | 有可偷的高价值道具（按偷取优先级命中） | 命中优先级即用 |

**连招示例**：放大镜看弹 → 实弹则手锯 ×2 伤害击敌，空弹则自击蝉联；手铐锁人后连动两轮。

### 2.5 边界与状态机细节

- 手铐跳过在**换边时**结算：被铐者回合直接跳过并换回，手铐状态消耗
- 手锯增益在**任意一次射击后**清除（含空弹射击），重装不清除
- 啤酒退光弹仓 → 立即重装 + 双方补发道具 + 清空私有信息与手铐记忆
- 过期药扣血至 0（含被肾上腺素偷用）→ 立即出局，对局结束
- 反转器翻转当前弹后，双方 `known_shells` 中该弹的记录同步翻转
- `simulate_match` 轻量模拟与 `GameSession` 共用同一套启发式与效果函数，保证基准与实战一致

### 2.6 对手建模（L2+ 信念引擎）

每位玩家持有一个对对手的**信念模型**（`engine/theory.py`），把决策从"我知道什么"升级为"对手知道什么、想干什么"。模型仅由公开信息驱动——道具栏、道具使用、射击行为、实/空配比均公开，**不含任何真实弹型泄露**。

**三层信念**

| 层 | 追踪内容 | 更新来源 |
|----|----------|----------|
| 信息层 | P(对手已知当前弹) | 放大镜/反转器使用（公开）、电话到期概率（偏移未知，按均匀分布近似） |
| 行为层 | 对手隐藏情报的存在性 | 贝叶斯行为反推（下表） |
| 威胁层 | 对手把情报转化为重击的能力 | 情报优势 × 道具栏（手锯/手铐）× 电荷差 |

**贝叶斯行为反推**（对手无可见情报时，行为即证据）

| 观察到的行为 | 推断 | 更新 |
|--------------|------|------|
| 对手用**手锯** | 几乎必然已知实弹 | `peek_live ≥ 0.9` |
| 公开 p ≥ 0.65 仍**自击**且打空 | 大概率握有空弹情报 | `behavior_info = 0.7`，`peek_live ≤ 0.15` |
| 公开 p ≤ 0.35 仍**击敌** | 可能握有实弹情报 | `behavior_info = 0.4`，`peek_live +0.25`（上限 0.85） |

指针前移后：放大镜类情报消费清零、电话到期推进（`phone_fired/pool`）、行为证据衰减 ×0.6；重装全量重置。

**威胁评估与决策融合**

```
damage = P(对手已知实弹) × (有锯 1.0 / 无锯 0.7)
tempo  = P(对手已知当前弹) × (有手铐 0.6 / 无 0.2)
threat = 0.65×damage + 0.25×tempo [+0.25 若我方濒死且对手已磨锯]
```

威胁从三个入口进入决策，全部受人格参数调制（**人格不被磨平**）：

1. **效用内核威胁偏置**：`diff += C × 0.4 × threat`——对手威胁越高越倾向击敌抢回行动权；低 C（冲动）人格几乎无视威胁读数
2. **防御性啤酒**：推断对手握实弹情报且有锯（`P ≥ 0.55`）→ 退弹销毁其确定性连招，概率 `0.5 + 0.4×C`
3. **防御性手铐**：`threat ≥ 0.6` → 锁住对手下回合阻断连招，沿用 `0.4 + 0.6×C`

**实战特征**（5,000 届 full 套统计）：威胁信号在约 4–5% 的决策时刻被激活；激活时攻击率较基线提升 10–15 个百分点；高 C 选手（Claude/GPT）威胁响应占比最高。

### 2.7 人格约束进化（CMA-ES）

在**不破坏人格**的前提下自动调参：每位选手在 R/S/C/L 各自 **±30%** 的参数域内，用 CMA-ES 搜索最强参数组合。

**流程**（`engine/evolve.py`）

1. **归一化搜索空间**：参数映射到以模板值为中心、±30% 半径的归一化坐标 `[−1, 1]`
2. **适应度**：候选参数 vs 五名模板选手的循环赛胜率（自私优化近似——其余五人保持模板值）
3. **标准 CMA-ES**：4 维、popsize 6、16 代；候选裁剪到域内（评估用裁剪解、分布更新用原始解，防止边界塌缩）
4. **CRN 降噪**：同代候选共用对局种子流（Common Random Numbers），参数差异是胜率差异的唯一来源
5. **决赛复评**：进化期 top-3 唯一参数 + 原始模板，用 4 倍样本（4,000 届）复评，取最优

**人格保持的硬保证**：所有进化结果被裁剪在 ±30% 域内；R/S/C/L 中心值不变，人格标签与参数排序保持。进化结果存 `benchmarks/evolved_params.json`，**不替换默认模板**——既有基准全部可复现。

复现：

```bash
python -m engine.evolve --generations 16 --popsize 6 --tournaments 1000   # 正式进化
python -m engine.evolve --smoke                                          # 冒烟
python benchmarks\run_evolved_benchmark.py                               # 进化后 10 万届验证
```

## 3. 选手模板

六名选手的性格参数按 $R$ 升序（攻击阈值从低到高）排列：

| # | 选手 | 角色定位 | $R$ | $S$ | $C$ | $L$ |
|---|------|----------|-----|-----|-----|-----|
| 1 | Claude | 谨慎稳定 | 0.16 | 0.65 | 0.75 | 0.02 |
| 2 | GPT | 理性中庸 | 0.17 | 0.50 | 0.60 | 0.04 |
| 3 | Kimi | 学习进化 | 0.20 | 0.45 | 0.40 | 0.08 |
| 4 | Gemini | 激情波动 | 0.24 | 0.30 | 0.25 | 0.10 |

**策略含义**：$R$ 为攻击阈值——Claude($R=0.16$) 最早攻击保命（谨慎），DeepSeek($R=0.32$) 最晚攻击赌命（赌徒）。在俄罗斯轮盘中，攻击对手 = 保命、自击 = 赌空枪。$S$ 决定策略一致性，$C$ 决定情绪抗性，$L$ 为噪声——高 $L$ 让赌徒在危险时也不一定攻击，反而自毁。
